## Acceptance Criteria

- Expected behavior is implemented.
- Existing functionality continues working.
- Automated tests cover the new behavior.
- All tests pass.

## Workflow

### 1. Plan

Analyze the task before modifying code.

Identify:

- Files that need modification
- Architecture impact
- Tests required
- Potential risks

### 2. Implement

Implement the smallest maintainable solution.

Follow the rules defined in AGENTS.md.

### 3. Test

Run:

python scripts/verify.py

### 4. Verify

Confirm:

- Requirements are satisfied
- Tests pass
- No existing behavior was broken
- No secrets were introduced

### 5. Review

Review the final changes for:

- Correctness
- Readability
- Maintainability
- Security

## Definition of Done

The task is complete only when implementation, tests,
verification, and review have succeeded.
