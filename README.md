# Enterprise AI Platform

Enterprise AI Platform is an end-to-end AI Engineering project built with Python and FastAPI.

The goal of the project is to integrate modern AI Engineering capabilities into a single production-oriented architecture, including LLM applications, RAG, advanced retrieval, context engineering, agentic workflows, evaluation, MLOps, observability, security and scalable AI services.

> Current status: Active development
